源码仓库：[qq550723504/data-forge](https://github.com/qq550723504/data-forge)。用户于 2026-10-28 明确确认公开上传此原型源码。

仓库公开不代表授予开源许可证；本次没有新增许可证。package.json 的 `private: true` 用于防止误发布到 npm，与 GitHub 仓库可见性无关。

企业数据准备、标注、模型开发与智能应用的本地前端交互原型。当前包含四项 P1 流程、文本/图片 AI 标注闭环和第一版治理层。

**前端模拟，未接真实后端。** 训练、预标注预测、评测、推理、模型发布、资源调度、权限和 API 授权均在浏览器中模拟，不代表真实模型效果、计费或服务器安全能力。原型不需要 API 密钥，不应输入生产凭据或敏感业务数据。

## 本地运行

已验证环境：Node.js 24.18.1、npm 11.16.0。依赖版本由 package-lock.json 锁定。

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

开发地址以终端实际输出为准，通常为 http://127.0.0.1:5173/。构建与仅本机预览：

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

该预览地址为 http://127.0.0.1:4173/。端口已占用时先确认原进程身份，不要终止其他应用。

## 数据与兼容性

- 本地 CSV/JSON、文档正文和图片可在浏览器中处理；IndexedDB 保存当前浏览器会话。跨电脑需要手动导出/导入完整快照。
- examples/ 是合成演示数据；账号邮箱均使用 example.com，不是可登录账号。历史内部身份 ID 和存储 key 保留，以兼容旧快照；显示名已去除本机用户个性化信息。
- 本仓库仅包含按原交付清单选取的源码、锁文件、字体、品牌资源、测试、合成快照与核验材料。没有复制浏览器当前数据、真实账号凭据、node_modules、本机路径或构建缓存。
- .openai/hosting.json 仅有空的 d1/r2 配置，保留原构建入口所需文件；仓库上传不包含部署或发布操作。
- source-manifest.json 记录本次整理后文件的 SHA256；history/ 中的旧清单对应原历史交付包，不能用于核验本次整理后的文件。

## 已接通的业务链

| 业务链 | 操作与约束 |
| --- | --- |
| 实际文本文件 → 生产版本 | CSV/JSON 真实解码、字段映射、错误行逐条提示与明确排除；清洗、分配、标注、审核返工、修订质检、冻结发布，保留文件校验报告 |
| 图片 → 标注数据交付 | 本地 PNG/JPEG/WebP 解码、原图像素框、显式无缺陷、分配审核返工、部分发布、JSON/COCO 导出 |
| 文档 → 知识来源 | TXT/Markdown 或可编辑正文；解析失败修复原文档和原任务；问题、答案、逐字段落引用、审核返工、独立来源版本 |
| 知识来源 → 可用索引 | 保存切分配置后构建；排队、失败与重试分别保留；只有当前配置的最新成功索引可检索，结果绑定来源版本、文档和段落；不匹配时返回空结果 |
| 数据版本 → 模型服务 | 文本分类与图像检测流程分开选型；成功训练登记模型；失败或取消不登记；修正参数后在同任务下重试；最新评测门槛、部署重试、调用与下线拒绝、完整来源回查 |
| 新服务/索引 → 智能体 | 独立 agentId/flowId、每节点独立配置，支持多个模型或检索节点；运行冻结输入、节点、服务、索引和来源；配置/输入/依赖变化提示历史结果已过期 |
| 应用反馈 → 改进 → 复测 | 成功调用或流程运行建立反馈；进入真实文本/图片改进批次或带引用的问答；新版本后用相同输入复测；只有包含该反馈修订的新来源才能关闭，旧运行被拒绝 |
| 成果 → 市场 → API 应用 | 真实发布数据、运行服务与有效索引进入唯一版本候选；上架、应用授权、到期、滚动分钟频率、撤权、下架及来源下线校验；旧访问快照保留 |
| 设置 → 业务约束 | 角色功能权限、授权项目/负责项目、标注人及审核分配、禁止自审；空间切换隔离业务对象；拒绝写入审计；这是客户端规则，不能替代服务器鉴权 |
| 配额 → 队列 → 释放 | 训练与知识索引共享空间并发，训练额外占用模拟 GPU；零额度排队；失败、成功与取消释放名额；在其他空间查看时后台仍推进 |
| 业务失败 → 告警 → 恢复 | 文档/索引/训练/评测/部署失败自动关联告警；有规则时生成本地通知记录；回到原对象恢复，确认处理且恢复成功后关闭并保留证据 |
| 工作 → 保存 → 恢复 | 工作台汇总当前可访问的真实待办；IndexedDB 自动保存；完整会话导出、格式/校验和/引用校验、导入恢复与撤销；系统备份入口执行实际原型快照 |

旧客服数据集的 1,160/880 等为历史演示统计；其发布样例实际只含 3 条记录。新接入批次、训练和评测按真实完整记录计算。知识分支不再显示固定 326 份文档或固定检索结果。

## 快速体验

- **自己的文本：**数据生产中心 → 数据接入 → 选择本地文件 → 映射字段、处理错误行 → 确认接入 → 清洗、标注、审核与发布。
- **知识闭环：**应用服务中心 → 知识生产与索引 → 接入正文（可选择模拟解析失败）→ 修复原任务 → 整理问答 → 提交/审核 → 发布来源 → 新建知识库/保存配置 → 构建索引 → 检索。
- **应用改进：**模型生产中心发布一个服务 → 智能体选择服务和索引 → 保存/运行 → 反馈 → 改进问答或批次 → 新版本 → 原问题复测 → 验证关闭。
- **市场：**数模服务中心 → 选择唯一成果 → 上架 → 指定应用授权 → 访问；可验证频率、撤权、下架和到期。模拟时间仅作用于本原型的授权验证。
- **权限和空间：**顶栏切换模拟成员或空间；在设置中修改自定义角色权限/成员授权，回业务页面验证。内置管理员角色保持只读。
- **备份：**运营与恢复，或系统设置 → 备份与恢复。刷新会恢复本浏览器已保存的数据；跨电脑需要手动导出和导入完整快照。

`examples/completed-session.json` 是实际浏览器导出并校验的演示会话，含已完成的知识反馈闭环、真实 CSV 发布版本和授权拒绝记录。可以在备份入口导入后快速查看。它使用合成业务内容，不包含真实训练或账号。

`examples/text-import-with-errors.csv` 为真实文件接入验收样例：将 body 映射到文本，record_id 映射到编号，source 映射到来源，expected 映射到参考标签。4 行中重复编号和空文本共 2 行错误，明确排除后接入 2 条。

## 边界

- 本地知识入口支持 TXT/Markdown/正文，不做 PDF/Word/OCR；索引是本地关键词检索，不是真正向量库。
- 模型元数据、同源标注回放、图像检测格式和规则答案不是权重、真实指标、真实推理或网络服务；图像评测不能解释为 mAP/IoU。
- 流程为顺序节点，不包含条件分支、循环或外部工具执行。
- 角色、空间、授权、GPU 和通知都由本地原型模拟，不是服务器安全边界、真实资源、真实 API 凭据或外发消息。
- IndexedDB 属于同一浏览器和页面来源；下载新文件、换浏览器/电脑时应使用完整快照迁移。未支持多浏览器协同或多标签冲突合并。
- 完整快照限制 80 MB；导入前先校验，恢复失败不改变当前数据。自动保存失败时页面会明确提示，不能声称已保存。
- 历史设置中的身份中心、远程连接、登录策略仍是配置演示；真实后端集成属于后续工程范围。
